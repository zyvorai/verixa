# Roadmap

0.1 implements stateful simulation, assertions, local trace recording/replay, fault injection,
version comparison, a CI exit-code gate, Python adapters, an OpenAI-compatible model adapter,
authenticated local console/API, SQLite history, exports and JUnit reports.

Next phases are not claimed as shipped:

1. MCP transport and framework adapters, production trace conversion/redaction.
2. Sandboxed adapter processes and Fabric Keep execution with verified receipts.
3. Browser task environments, richer state assertions and benchmark packs.
4. SSO/RBAC, job workers, parallel execution and artifact signing.
5. Provider pricing catalogs, managed connectors and enterprise deployment.
6. Learning from verified outcomes, with frozen holdout sets to prevent benchmark overfitting.
